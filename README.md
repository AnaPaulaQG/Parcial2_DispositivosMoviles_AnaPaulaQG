# Tematica elegida

- Tienda de ropa

# Descripcion del proyecto

- Es una aplicacion web que simula tener un catalogo de productos que propone lo siguiente: titulo del producto, categoria, precio, stock ademas de contar con un buscador y un desplegable que cuenta con diferentes opciones. Por ultimo, tiene un carrito que muestra si se agregaron productos o no.

# Instrucciones para correr el proyecto

- cd tienda-de-ropa (entra en el proyecto)
- npm install (instala las dependencias)
- npm run dev (inicia el servidor)
